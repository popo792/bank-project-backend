# Banker Management Dashboard - Backend

The backend service for the Banker Management Dashboard, designed to handle consumer loan processing, transaction tracking, and automated financial reporting. 

## Features
* **RESTful API:** Provides endpoints for real-time transaction filtering and status updates.
* **Database Integration:** Optimized queries for handling financial records securely.
* **Automated Reporting:** Integrates Python scripts to generate multi-sheet Excel reports for auditing.

## Tech Stack
* **Language:** Go (Golang)
* **Database:** MS SQL Server
* **Scripting:** Python (for report generation)

## Setup
1. Clone the repository.
2. Set your MS SQL Server connection string in the environment variables.
3. Run `go build` and execute the binary.
